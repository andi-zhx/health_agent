# Windows 启动排障

安装 64 位 Python 3.10–3.14（推荐 3.12），勾选 Add Python to PATH，将 ZIP 完整解压后双击启动。首次安装需要联网。

| 现象 | 处理 |
| --- | --- |
| 找不到 Python | 重新安装并勾选 PATH；在 CMD 输入 `py -3 --version` 检查 |
| 依赖安装失败 | 保留安装窗口的报错，确认网络和目录写入权限；重新运行 `start.bat --install-only` |
| 旧版 `.venv` 无效或来自其他电脑 | 关闭程序，将 `.venv` 改名为 `.venv-old`，再启动重新创建；不要改名或删除数据库 |
| 端口已占用 | 关闭之前的启动窗口；正式模式也可在 CMD 执行 `set APP_PORT=5001` 后 `call start.bat` |
| 浏览器没自动打开 | 正式模式访问 `http://127.0.0.1:5000`，演示模式访问 `http://127.0.0.1:5050`；先确认启动窗口没有报错 |
| 页面显示旧界面 | 按 `Ctrl+F5`，确认打开的是新版本对应端口 |
| 仍提示密钥错误 | 正常首次启动会创建 `.secret_key`；确认数据目录可写。已有密钥应保留，不要用空文件替换 |
| 看不到 100 条案例 | 使用 `启动V2演示系统.bat`，选择年度范围；正式库不会自动混入案例 |
| 正式项目人数比旧版少 | 检查日期范围与待核验项目映射；归档项目没有删除，但未核验前不计入正式六项统计 |

详细运行日志位于实际数据目录的 `logs/app.log`。在 CMD 从项目目录执行 `start.bat` 可保留可读的错误信息。升级、数据目录和回滚方法见 [V2 验收说明](v2-acceptance.md)。
